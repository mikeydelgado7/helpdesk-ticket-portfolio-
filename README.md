# Help Desk Ticket Portfolio (Career Changer)

This repository demonstrates my ability to perform Help Desk / Service Desk responsibilities through realistic ticket scenarios, troubleshooting runbooks, and knowledge base documentation.

## What this shows
- Ticket triage (impact, urgency, prioritization)
- Clear user communication and documentation
- Windows troubleshooting (Outlook, printing, connectivity)
- Basic networking diagnostics (gateway vs internet vs DNS)
- Active Directory fundamentals (password resets, unlocks, share access)
- Escalation judgment and clean handoffs

## How to navigate
- **/tickets** → completed ticket write-ups (intake → troubleshooting → resolution)
- **/runbooks** → step-by-step internal procedures used to solve tickets
- **/knowledge-base** → end-user friendly articles
- **/templates** → reusable templates for tickets, runbooks, and KB articles
