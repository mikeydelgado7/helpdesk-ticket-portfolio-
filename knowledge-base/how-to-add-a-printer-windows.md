# How to Add a Printer on Windows

## What this helps with
Installing a network printer so you can print from your computer.

## Steps
1. Open **Settings**
2. Go to **Bluetooth & devices → Printers & scanners**
3. Click **Add device**
4. Select your printer (or choose **Add manually** if it doesn’t show)
5. Print a **test page** to confirm

## If you still need help
Contact the Service Desk and include:
- Printer name/location (example: “2nd Floor Copier”)
- Any error message you see
