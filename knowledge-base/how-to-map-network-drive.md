# How to Map a Network Drive

## What this helps with
Connecting to a shared folder (for example: \\SERVER\Share) so it shows up as a drive letter in File Explorer.

## Steps
1. Open **File Explorer**
2. Click **This PC**
3. Click **Map network drive**
4. Choose a drive letter (example: **Z:**)
5. In Folder, type the path (example: **\\SERVER\Share**)
6. Click **Finish**

## If you still need help
Contact the Service Desk and include:
- The path you used (\\server\share)
- Screenshot of the error (optional)
- Whether you are on VPN (if remote)
